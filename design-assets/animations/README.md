# ClawStatus 动画序列帧

## 目录结构

```
animations/
├── idle/      # 🟢 空闲状态（8 帧）
├── busy/      # 🟡 忙碌状态（10 帧）
├── fire/      # 🔥 火爆状态（10 帧）
├── error/     # 🔴 错误状态（8 帧）
└── offline/   # ⚫ 离线状态（8 帧）
```

## 动画规格

- **尺寸：** 64x64 像素
- **格式：** PNG（带透明通道）
- **帧率：** 30fps（推荐）
- **命名：** `frame_001.png`, `frame_002.png`, ...

## 状态说明

### 🟢 Idle (空闲)
- **帧数：** 8 帧
- **效果：** 蓝色呼吸灯，胸部发光区域明暗变化
- **循环：** 无缝循环
- **颜色：** #4A90E2 (蓝色)

### 🟡 Busy (忙碌)
- **帧数：** 10 帧
- **效果：** 橙色常亮，触须轻微摆动
- **循环：** 无缝循环
- **颜色：** #FFA500 (橙色)

### 🔥 Fire (火爆)
- **帧数：** 10 帧
- **效果：** 红色闪烁，多触须快速摆动
- **循环：** 无缝循环
- **颜色：** #FF0000 (红色)

### 🔴 Error (错误)
- **帧数：** 8 帧
- **效果：** 红色强闪烁，警示姿态
- **循环：** 可循环或单次播放
- **颜色：** #FF0000 (红色)

### ⚫ Offline (离线)
- **帧数：** 8 帧
- **效果：** 灰色熄灭，灯光逐渐关闭
- **循环：** 单次播放后保持最后一帧
- **颜色：** #4A4A4A (灰色)

## 设计指南

### 机械龙虾吉祥物

1. **头部/胸部特写：** 64x64 像素下聚焦于头部和胸部发光区
2. **眼睛：** 红色，表达不同情绪
3. **触须：** 根据状态调整摆动幅度
4. **胸部发光区：** 核心状态指示器

### 动画原则

- **呼吸效果：** 使用透明度或亮度渐变实现
- **闪烁效果：** 明暗快速交替
- **摆动效果：** 触须位置轻微偏移

## 制作工具推荐

- **Figma：** 矢量设计，导出 PNG 序列
- **Photoshop：** 帧动画，时间轴导出
- **After Effects：** 复杂动画，导出序列帧
- **Blender：** 3D 渲染（如需 3D 效果）

## 文件命名规范

```
{state}/frame_{number:D3}.png

示例：
idle/frame_001.png
idle/frame_002.png
...
busy/frame_001.png
```
